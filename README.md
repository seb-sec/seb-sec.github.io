# Blog

Theme adapted from https://owickstrom.github.io/the-monospace-web/

## Build

Place files in `src/` directory. Markdown files will be used to build HTML
files that form the site using `pandoc`.

```
./build.sh
```

Output will be in the `docs/` directory.
